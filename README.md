# Fetherstill Admin

Admin dashboard for managing the Fetherstill platform, built with React + Vite and integrated with Firebase/auth-enabled backend APIs.

## Tech Stack

- React (`.jsx`)
- Vite
- JavaScript (ES modules)
- Firebase
- Custom service layer (`src/services`)
